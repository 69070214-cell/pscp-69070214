# บันทึกการแก้โจทย์

ไฟล์นี้ต้องเขียนโดยนักศึกษาด้วยคำพูดของตนเอง

ใช้ template นี้เฉพาะกับโจทย์ OJ ที่ถูกระบุว่าต้องส่ง learning log เท่านั้น

ห้ามให้ AI เขียนไฟล์นี้แทนคุณ AI อาจช่วยตรวจ grammar, formatting หรือความชัดเจนได้ หลังจากที่คุณเขียนเนื้อหาของตนเองแล้ว

ถ้าใช้ AI กับโจทย์ learning-log-required นี้ ต้องทำไฟล์ `ai_reflection.md` ด้วย

## 2. ความเข้าใจโจทย์ของฉัน

เขียนโจทย์ด้วยคำพูดของตนเอง

ให้อธิบาย input, output และ constraints สำคัญด้วย

ถ้ายังไม่เข้าใจโจทย์ทั้งหมด ให้เขียนสิ่งที่เข้าใจในตอนนี้ ความเข้าใจอาจยังไม่ครบหรืออาจผิดได้ แต่ต้องพยายามอธิบายอย่างจริงใจ

```text
Input:
รับค่าRGBของสี2สี มี2บรรทัด แต่ละบรรทัดจะมีตัวเลข3ตัวคั่นด้วยช่องว่าง

Output:
แสดงค่าRGBที่ได้จากการผสมสี2สี มีเลข3เลข คั่นด้วยช่องว่าง

Constraints:
การผสมสีจะคำนวนจากการเอาค่าRGBของ2สีบวกกันแล้วหาร2 (เอาเลข3ตำแหน่งของแต่ละสีมาบวกกันแล้วหารด้วย2) การบวกเลขจะบวกในตำแหน่งที่ตรงกันเท่านั้น เช่น เลขตำแหน่งแรกของสีที่1ก็จะบวกกับตำแหน่งแรกของสีที่2เท่านั้น
```

## 3. แผนแรกของฉัน

เขียนแผนแรกก่อนรับความช่วยเหลือจาก AI เพื่อน TA ผู้สอน หรือก่อนสรุป code สุดท้าย

ถ้าใช้ AI ให้เขียนแผนที่มีอยู่ก่อน prompt แรกที่ถาม AI

ถ้าถามเพื่อน TA หรือผู้สอน ให้เขียนแผนที่มีอยู่ก่อนถาม

ถ้าไม่ได้ใช้ AI และไม่ได้ขอความช่วยเหลือจากคน ให้เขียนแผนที่มีอยู่ก่อนหรือระหว่างเริ่มเขียน code

แผนนี้เขียนแบบคร่าว ๆ ได้ อาจยังไม่สมบูรณ์หรืออาจต่างจากวิธีสุดท้าย

สามารถเขียนเป็น pseudocode, flowchart idea หรือขั้นตอนความคิดได้

```text
Step 1: สร้างฟังก์ชันmixcolor รับค่าสีRGB 2สี(c1,c2)เป็นจำนวนเต็ม
Step 2: นำสีทั้ง2สีมาบวกกันแล้วหาร2
Step 3: สร้างฟังก์ชันผสมสี(mix_rgb) รับค่าสี2สี (color1,color2)เป็นจำนวนเต็ม
Step 4: กำหนด การผสมสีแดงเท่ากับค่าที่ได้จากการส่งค่าตำแหน่งที่0ของcolor1,color2เข้าไปในฟังก์ชันmixcolor(ในฟังก์ชันจะเอา2เลขบอกกันแล้วหาร2) แล้วได้ผลลัพเป็น rMix
Step 5: กำหนด การผสมสีเขียวเท่ากับค่าที่ได้จากการส่งค่าตำแหน่งที่1ของcolor1,color2เข้าไปในฟังก์ชันmixcolor แล้วได้ผลลัพเป็น gMix
Step 6: กำหนด การผสมสีน้ำเงินเท่ากับค่าที่ได้จากการส่งค่าตำแหน่งที่2ของcolor1,color2เข้าไปในฟังก์ชันmixcolor แล้วได้ผลลัพเป็น bMix
Step 7: สร้างฟังก์ชัน main รับค่าRGBสี2สี 2บรรทัด บรรทัดละ3เลข คั่นด้วยช่องว่าง เก็บในตัวแปร r1 ,g1,b1,r2 ,g2 ,b2
Step 8: กำหนดให้rMix , gMix , bMix เป็นค่าที่ได้จากการนำ(r1,g1,b1),(r2,g2,b2)ไปคำนวนในฟังก์ชันmix_rgb
Step 9: แสดงผลค่า rMix , gMix , bMix ออกมา โดยเว้นวรรคระหว่างเลขแต่ละเลข
Step 10: เรียกใช่ฟังก์ชัน main 1ครั้ง
```

## 4. วิธีสุดท้ายที่ใช้จริง

อธิบายสั้น ๆ ว่า algorithm หรือวิธีสุดท้ายที่ใช้จริงใน code ที่ส่งคืออะไร

หัวข้อนี้ต่างจาก Section 3:

- Section 3 คือแผนแรกก่อนใช้ AI ก่อนรับความช่วยเหลือจากคน หรือก่อนเขียน code สุดท้าย
- Section 4 คือวิธีสุดท้ายที่ใช้ใน solution จริง
- ถ้าวิธีสุดท้ายเหมือนกับแผนแรก ให้เขียนว่าเหมือนกัน และอธิบายสั้น ๆ ว่าทำไม

ห้ามคัดลอกคำอธิบายจาก AI

ห้ามคัดลอกคำอธิบายจากคนอื่น

```text
วิธีสุดท้ายเหมือนกับแผนแรก มีการสร้างฟังก์ชันmixColorผสมสีโดยเอาเลข2เลขบวกกันแล้วหาร2  สร้างฟังก์ชันmixRGBเพื่อคำนวนสีแต่ละตำแหน่ง (rMix, gMix, bMix) โดยการเอาค่าสีไปคำนวนในฟังก์ชันmixColor ทีละตำแหน่ง และสร้างฟังก์ชัน main รับค่าสี2สี แล้วนำค่าที่รับไปคำนวนในฟังก์ชันmixRGB จะได้ผลลัพเป็นค่าrMix , gMix , bMix แล้วแสดงผลโดยเรียกใช้ฟังก์ชัน main
```

- อธิบายความหมายของโจทย์
- อธิบาย concept การเขียนโปรแกรม
- ให้ hint เกี่ยวกับแนวทาง
- คุยเรื่อง debugging
- คุยเรื่อง test cases
- ช่วยอธิบาย error message

- คัดลอก code ของผู้อื่น
- ส่ง solution ของผู้อื่น
- ขอให้ผู้อื่นเขียน solution ให้
- ใช้ OJ submission ของผู้อื่น
- ขอให้ผู้อื่นส่ง OJ แทน
